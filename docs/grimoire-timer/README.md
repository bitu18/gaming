# Grimoire Timer

A parchment-and-witchcraft themed Timer / Stopwatch, single-page and dependency-free.

## Run it

Open `index.html` directly in a browser — no build step or server required.

## Structure

```
grimoire-timer/
├── index.html      entry point: markup, styles, and app logic
└── assets/         hand-illustrated PNG art used by index.html
    └── README.txt  notes on the asset pack (blank frames vs. reference art)
```

## Features

- Timer and Stopwatch modes
- Quick-add buttons (+0:30 / +1:00 / +5:00)
- Click the time to type an exact value
- Start / pause, reset, sound toggle, fullscreen
